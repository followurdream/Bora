# Bora - AI 이미지/영상 뉴스 브리핑

해외 AI 뉴스를 **이미지 탭 / 영상 탭**으로 나눠서, 한국어 번역 + 요약 형태로 깔끔하게 보여주는 웹 페이지입니다.

## 이번 개선사항

- 기사 텍스트만이 아니라 **기사 관련 이미지(썸네일)** 를 카드에 함께 표시
- 카테고리(이미지/영상)별로 **상위 5개 뉴스만** 추려서 표시
- 더 보기 편한 인터페이스로 개선
  - 히어로 헤더
  - 라운드 탭 버튼
  - 이미지 + 본문 2열 카드(모바일 반응형)

## 핵심 기능

- 해외 뉴스 수집: Google News RSS 검색 기반
- 번역: 영문 제목/요약을 한국어로 자동 번역 (실패 시 원문 유지)
- 정리된 카드 UI: 원문 전체를 그대로 가져오지 않고 핵심 정보만 표시
  - 번역 제목
  - 원문 제목
  - 요약 번역
  - 출처 / 발행 시각
  - 원문 링크
  - 관련 이미지
- 탭 분리: `이미지`, `영상`

## 실행 방법

```bash
python web_app.py
```

브라우저에서 아래 주소를 열면 됩니다.

- `http://localhost:8000`

## 파일 구성

- `web_app.py`: 뉴스 수집/파싱/번역/요약 + 웹 렌더링
- `tests/test_web_app.py`: RSS 파싱, 이미지 추출, 요약, 번역 폴백, 데이터 준비 테스트
- `api_builder.py`: 기존 API 빌더 유틸 (별도 사용 가능)
- `tests/test_api_builder.py`: 기존 API 빌더 테스트

## 테스트

```bash
python -m unittest discover -s tests -v
```
